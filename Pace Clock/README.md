# Pace Clock

Standalone countdown app: https://progressive-round-timer.sure-lamp-8039.chatgpt.site

Open `dist/index.html` directly or serve the `dist` directory with any static web server. No dependencies or build step are required. The app is also available from Relay Optimizer’s Pace Clock menu item.

Set the starting duration, change per round (positive, negative, or zero), and optional round limit. Each round starts automatically. Start, pause, resume, sound, and reset confirmation are included. Keep the page open for reliable timing and sound.

The app is published publicly so it opens without a ChatGPT sign-in. Public access is a hosting setting, managed separately from these files. `.openai/hosting.json` retains the existing standalone Site identity.
